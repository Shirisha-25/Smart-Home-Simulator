# Smart Home Simulator

## Project Overview

Smart Home Simulator is a console-based Java application that simulates common smart home devices such as Light, Fan, and Air Conditioner.

The application allows users to turn devices ON/OFF, control fan speed, set AC temperature, and view device status.

## Technologies Used

- Java
- Core Java
- Object-Oriented Programming
- Interface
- ArrayList
- Scanner
- VS Code

## Features

- Turn Light ON/OFF
- Turn Fan ON/OFF
- Set Fan Speed from 1 to 5
- Turn AC ON/OFF
- Set AC Temperature from 16°C to 30°C
- View all device statuses
- Menu-driven console application
